## 一言でいうと

ある因子は大きな単位（大区画）ごとにしか変えられず、別の因子は大区画を分けた小さな単位（小区画）ごとに変えられるときの実験計画です。
無作為化が2段階になるので、誤差も「1次誤差」と「2次誤差」の2種類になります。

## 定義・数式

ブロック（反復）$R$ が $r$ 個、1次因子 $A$ が $a$ 水準、2次因子 $B$ が $b$ 水準の分割法を考えます。

1. 各ブロックを $a$ 個の**大区画**（1次単位）に分け、$A$ の水準を乱数で割り付けます。
2. 各大区画を $b$ 個の**小区画**（2次単位）に分け、$B$ の水準を乱数で割り付けます。

モデルは

$$
y_{kij}=\mu+\rho_k+\alpha_i+\delta_{ki}+\beta_j+(\alpha\beta)_{ij}+\varepsilon_{kij}
$$

$$
\delta_{ki}\sim N(0,\sigma_1^2)\ (\text{1次誤差}),\qquad \varepsilon_{kij}\sim N(0,\sigma_2^2)\ (\text{2次誤差})
$$

で、$\delta$ と $\varepsilon$ はすべて互いに独立とします。分散分析表は次のように2段に分かれます。

| 段 | 要因 | 自由度 | 期待平均平方 | F の分母 |
|---|---|---|---|---|
| 1次単位 | ブロック R | $r-1$ | | $V_{E_1}$ |
| | A | $a-1$ | $\sigma_2^2+b\sigma_1^2+\dfrac{rb\sum\alpha_i^2}{a-1}$ | $V_{E_1}$ |
| | 1次誤差 $E_1$（R×A） | $(r-1)(a-1)$ | $\sigma_2^2+b\sigma_1^2$ | |
| 2次単位 | B | $b-1$ | $\sigma_2^2+\dfrac{ra\sum\beta_j^2}{b-1}$ | $V_{E_2}$ |
| | A×B | $(a-1)(b-1)$ | $\sigma_2^2+\dfrac{r\sum\sum(\alpha\beta)_{ij}^2}{(a-1)(b-1)}$ | $V_{E_2}$ |
| | 2次誤差 $E_2$ | $a(r-1)(b-1)$ | $\sigma_2^2$ | |
| | 合計 | $rab-1$ | | |

## 数式の読み解き

- **1次誤差**：同じ A の水準を割り付けた大区画どうしのばらつきです。大区画全体にかかる誤差 $\delta_{ki}$ を含むので、期待値は $\sigma_2^2+b\sigma_1^2$ と大きくなります。A の比較は大区画単位なので、この誤差で検定します。
- **2次誤差**：大区画の中の小区画どうしのばらつきです。B と A×B は同じ大区画の中で比較できるので、大区画間のばらつきの影響を受けず、小さい誤差で検定できます。
- 1次誤差の平方和は、ブロックと A の組合せ（大区画）の平方和から、ブロックと A の平方和を引いて求めます。

$$
S_{E_1}=S_{RA}-S_R-S_A,\qquad S_{E_2}=S_T-S_{RA}-S_B-S_{A\times B}
$$

- 期待平均平方を見ると、A の検定を $V_{E_2}$ で行うと分母が小さすぎ、有意になりやすくなる（第1種の過誤が増える）ことがわかります。
- 分割法は、A の精度を犠牲にして、B と A×B の精度を上げる計画です。変えにくい因子・関心の低い因子を1次因子にします。

## 具体例

**例1：灌水方法（大区画）と品種（小区画）**

灌水方法 A（2種類）は水路ごとにしか変えられないので大区画に、品種 B（2種類）は小区画に割り付けました。ブロックは3つです。

| ブロック | A1・B1 | A1・B2 | A2・B1 | A2・B2 |
|---|---|---|---|---|
| R1 | 40 | 44 | 46 | 51 |
| R2 | 45 | 48 | 45 | 53 |
| R3 | 39 | 43 | 47 | 52 |

総合計 553、$CT=553^2/12=25484.083$、$\sum y^2=25699$ です。

大区画（R×A）の合計は 84, 97, 93, 98, 82, 99、ブロック合計は 181, 191, 181、A の合計は 259, 294、B の合計は 262, 291、A×B のセル合計は 124, 135, 138, 156 です。

$$
\begin{aligned}
S_T&=25699-25484.083=214.917\\
S_{RA}&=\tfrac{84^2+97^2+93^2+98^2+82^2+99^2}{2}-CT=137.417\\
S_R&=16.667,\quad S_A=102.083,\quad S_{E_1}=137.417-16.667-102.083=18.667\\
S_{AB}&=\tfrac{124^2+135^2+138^2+156^2}{3}-CT=176.250\\
S_B&=70.083,\quad S_{A\times B}=176.250-102.083-70.083=4.083\\
S_{E_2}&=214.917-137.417-70.083-4.083=3.333
\end{aligned}
$$

| 要因 | 平方和 | 自由度 | 平均平方 | F 値 | p 値 |
|---|---|---|---|---|---|
| ブロック R | 16.667 | 2 | 8.333 | 0.893 | 0.528 |
| 灌水 A | 102.083 | 1 | 102.083 | 10.938 | 0.0805 |
| 1次誤差 | 18.667 | 2 | 9.333 | | |
| 品種 B | 70.083 | 1 | 70.083 | 84.100 | 0.0008 |
| A×B | 4.083 | 1 | 4.083 | 4.900 | 0.0913 |
| 2次誤差 | 3.333 | 4 | 0.833 | | |
| 合計 | 214.917 | 11 | | | |

品種 B は有意、灌水 A は5%水準で有意ではありません。

**例2：誤差を取り違えると**

A を2次誤差で割ると $F=102.083/0.833=122.5$、$p=0.0004$ となり「高度に有意」と誤った結論になります。大区画は実質 $3\times2=6$ 個しかなく、A の比較の精度はその数で決まります。

## 現場での使われ方

- **農業**：灌水・耕起の方法など大きな面積単位でしか変えられない処理を大区画に、品種や施肥量を小区画に割り付けます。
- **製造・品質管理**：炉の温度は1回の焼成ごと（大区画）にしか変えられず、同じ炉に入れる材料の種類（小区画）は一度に複数試せる、という実験で使います。
- **食品**：仕込みのロット（大区画）ごとに製法を変え、同じロットを小分けして保存条件（小区画）を変える試験に使います。

## グラフ・イメージ

例1の2種類の誤差の平均平方を比べた棒グラフです。1次誤差は2次誤差の10倍以上あり、1次因子 A の検定には不利な誤差を使うことがわかります。

## 試験のポイント

- 1次誤差と2次誤差の自由度、とくに $(r-1)(a-1)$ と $a(r-1)(b-1)$ を正確に出せるようにします。
- どの要因をどちらの誤差で検定するか（A は1次誤差、B と A×B は2次誤差）が重要です。
- 無作為化が2段階であることが分割法の本質です。全組合せを一度に無作為化する二元配置（乱塊法）との違いを説明できるようにします。
- 期待平均平方 $E[V_{E_1}]=\sigma_2^2+b\sigma_1^2$ から、1次誤差が2次誤差より大きくなる理由を理解します。

## よくある間違い

- × 分割法のデータを普通の二元配置として、すべて同じ誤差で検定する → ○ 1次因子は1次誤差で検定します。同じ誤差を使うと1次因子が過大に有意になります。
- × 1次誤差を「ブロックの平方和」とみなす → ○ 1次誤差はブロック×A の交互作用（大区画どうしのばらつき）です。ブロックの主効果とは別の行です。
- × 精度を上げたい因子を大区画に割り付ける → ○ 大区画の因子は精度が低くなります。精度を上げたい因子や交互作用は小区画に割り付けます。

## 一言でいうと

分散分析の結果を、**変動の原因（要因と誤差）ごとに、平方和・自由度・平均平方・F 比**の順に並べた表です。
「群の平均の違いによる変動」が「群の中の偶然の変動」に比べて十分大きいかを F 比で判断します。

## 定義・数式

$k$ 個の群、全体で $N$ 個のデータの一元配置分散分析の表：

| 要因 | 平方和 | 自由度 | 平均平方 | F 比 |
|---|---|---|---|---|
| 群間（処理） | $S_A$ | $k-1$ | $V_A = S_A/(k-1)$ | $F = V_A/V_E$ |
| 群内（誤差） | $S_E$ | $N-k$ | $V_E = S_E/(N-k)$ | |
| 全体 | $S_T$ | $N-1$ | | |

- 全体の平方和：$S_T = \sum(\text{各データ} - \text{全体平均})^2$
- 群間の平方和：$S_A = \sum_{\text{群}} n_j(\text{群の平均} - \text{全体平均})^2$
- 群内の平方和：$S_E = \sum(\text{各データ} - \text{その群の平均})^2$

平方和と自由度は足し算で分解できます：$S_T = S_A + S_E$、$N-1 = (k-1)+(N-k)$。

「すべての群の母平均が等しい」という帰無仮説のもとで、$F$ は自由度 $(k-1,\ N-k)$ の F 分布にしたがいます。

## 数式の読み解き

- 平均平方は「平方和を自由度で割った」分散の推定値です。誤差の平均平方 $V_E$ は、群の中のばらつき（誤差分散）の推定値になります。
- 群の母平均がすべて等しければ $V_A$ も誤差分散と同じくらいの大きさになり、$F$ は 1 前後です。平均に差があると $V_A$ が大きくなり、$F$ が大きくなります。
- 表の空欄は、「平方和と自由度の足し算」と「平均平方＝平方和÷自由度」「F＝平均平方の比」から埋められます。
- 回帰分析の出力にも同じ形の表があり、「回帰」と「残差」に分けて F 値を計算します。

## 具体例

3 つの教え方 A・B・C を、5 人ずつ無作為に割り付けて点数を比べました。

| 教え方 | 点数 | 平均 |
|---|---|---|
| A | 60, 65, 70, 62, 68 | 65 |
| B | 70, 72, 75, 68, 75 | 72 |
| C | 58, 62, 60, 55, 65 | 60 |

全体平均は $197/3\approx 65.67$。群間の平方和は $5\{(65-65.67)^2+(72-65.67)^2+(60-65.67)^2\}\approx 363.3$、群内の平方和は $68+38+58=164$ です。

| 要因 | 平方和 | 自由度 | 平均平方 | F 比 |
|---|---|---|---|---|
| 教え方 | 363.3 | 2 | 181.7 | 13.29 |
| 誤差 | 164.0 | 12 | 13.67 | |
| 全体 | 527.3 | 14 | | |

F 分布表の上側 5% 点 $F_{0.05}(2,12)=3.885$ より大きいので、有意水準 5% で「教え方によって平均点に差がある」と判断します（p 値は約 0.0009）。

## 現場での使われ方

- **実験の報告**：農業・工業・医学の実験結果を、分散分析表の形でまとめて示します。
- **統計ソフトの出力**：ソフトは分散分析表と p 値を出力するので、どの要因が有意かを表から読み取ります。
- **回帰分析**：回帰全体が意味を持つかを、回帰の分散分析表の F 値で確かめます。

## グラフ・イメージ

自由度 (2, 12) の F 分布です。帰無仮説のもとで F 比はこの分布にしたがい、右の裾（上側 5%）に入れば帰無仮説を棄却します。

## 試験のポイント

- 空欄のある分散分析表を埋めさせる問題が定番です。自由度（群の数 −1、全体の個数 − 群の数）を正しく数えます。
- F 比と F 分布表の値を比べて結論を選ぶ問題、p 値から判断する問題が出ます。
- 分散分析で有意でも、「どの群とどの群に差があるか」まではわからないことを押さえます。

## よくある間違い

- × F 比＝平方和の比 → ○ 平均平方（平方和÷自由度）の比です。
- × 群内の自由度は群の数 − 1 → ○ 全体の個数 − 群の数（$N-k$）です。群間が $k-1$ です。
- × 有意なら、すべての群の平均が互いに違う → ○ 少なくとも 1 組に差があるということだけです。

## 一言でいうと

2 つの変数 $x$、$y$ の相関から、**第 3 の変数 $z$ の影響を取り除いた相関**です。
見かけの相関（擬似相関）かどうかを調べるのに使います。

## 定義・数式

$x$、$y$、$z$ の相関係数を $r_{xy}$、$r_{xz}$、$r_{yz}$ とすると、$z$ の影響を除いた $x$ と $y$ の偏相関係数は

$$
r_{xy\cdot z}=\frac{r_{xy}-r_{xz}\,r_{yz}}{\sqrt{(1-r_{xz}^2)(1-r_{yz}^2)}}
$$

です。$-1$ から $1$ の値をとります。

## 数式の読み解き

- 分子は、$x$ と $y$ の相関から「$z$ を通じて生じる分」$r_{xz}r_{yz}$ を引いたものです。
- 偏相関係数は、「$x$ を $z$ で回帰した残差」と「$y$ を $z$ で回帰した残差」の相関係数に等しくなります。どちらからも $z$ で説明できる部分を取り除いてから相関を見ているのです。
- 偏相関係数が 0 に近ければ、$x$ と $y$ の相関は $z$ による見かけの相関だったと考えられます。逆に、$z$ が $x$ と $y$ に逆向きに関係していると、偏相関係数のほうが元の相関より大きくなることもあります。
- 2 級では $z$ が 1 つの場合の公式を使います。

## 具体例

ある地域の 40 の町で、商店の数 $x$、自転車の盗難の件数 $y$、人口 $z$ の相関係数が $r_{xy}=0.7$、$r_{xz}=0.6$、$r_{yz}=0.8$ でした。

$$
r_{xy\cdot z}=\frac{0.7-0.6\times 0.8}{\sqrt{(1-0.36)(1-0.64)}}=\frac{0.22}{\sqrt{0.2304}}=\frac{0.22}{0.48}\approx 0.46
$$

元の相関 0.7 のうちかなりの部分は人口を通じたものですが、人口の影響を除いても 0.46 の相関が残ります。商店が多いこと自体（自転車で来る客が多いなど）にも盗難と関係する理由があるかもしれません。

## 現場での使われ方

- **社会調査**：収入と健康の関係を、年齢の影響を除いて調べるなど、交絡しそうな変数の影響を取り除きます。
- **医学**：2 つの検査値の関係を、体格（体重など）の影響を除いて調べます。
- **回帰分析との関係**：重回帰の係数も、ほかの変数の影響を除いた関係を表す点で、偏相関係数と同じ考え方です。

## グラフ・イメージ

$Z$ が $X$ と $Y$ の両方に影響するモデルの散布図です。$Z$ の影響を強くすると、$X$ と $Y$ の見た目の相関が強くなりますが、$Z$ の影響を除いた偏相関係数はいつも 0 です。

## 試験のポイント

- 3 つの相関係数から偏相関係数を公式で計算する問題が定番です。分母の平方根に注意します。
- 偏相関係数が 0 に近いとき、元の相関を擬似相関と判断する問題がよく出ます。
- 層別の散布図や重回帰の係数とあわせて、「第 3 の変数の影響を除く」考え方を押さえます。

## よくある間違い

- × 偏相関係数は、元の相関係数から $r_{xz}r_{yz}$ を引いただけ → ○ 分子を $\sqrt{(1-r_{xz}^2)(1-r_{yz}^2)}$ で割ります。
- × 偏相関係数はいつも元の相関より小さい → ○ $z$ との関係の向きによっては大きくなることもあります。
- × 偏相関係数が 0 なら、$x$ と $y$ の相関係数も 0 → ○ 元の相関は 0 でなくても、$z$ の影響を除くと 0 になることがあります（擬似相関）。

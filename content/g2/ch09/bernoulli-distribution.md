## 一言でいうと

「成功か失敗か」「賛成か反対か」のように**結果が 2 通りしかない 1 回の試行**をベルヌーイ試行といい、成功を 1、失敗を 0 で表した確率変数の分布をベルヌーイ分布といいます。
二項分布や標本比率の土台になる、いちばん単純な分布です。

## 定義・数式

成功の確率を $p$ とし、成功なら $X=1$、失敗なら $X=0$ とします。

$$
P(X=1)=p,\qquad P(X=0)=1-p
$$

期待値と分散は

$$
E[X]=p,\qquad V[X]=p(1-p)
$$

です。

## 数式の読み解き

- 期待値は $1\times p+0\times(1-p)=p$ です。$X^2$ も 0 か 1 なので $E[X^2]=p$ となり、$V[X]=E[X^2]-(E[X])^2=p-p^2=p(1-p)$ が出ます。
- 分散 $p(1-p)$ は $p=0.5$ で最大の 0.25 になり、$p$ が 0 や 1 に近いほど小さくなります。結果がほぼ決まっているときは散らばりが小さい、ということです。
- 独立なベルヌーイ試行を $n$ 回くり返したときの成功の回数は二項分布 $B(n,\ p)$ にしたがいます。成功の回数を $n$ で割ったものが**標本比率**です。
- 0 と 1 で表したデータの平均は、1 の割合に等しくなります。だから比率の問題は「0 と 1 のデータの平均」の問題として扱え、標本比率の分散は $p(1-p)/n$ になります。

## 具体例

**例 1：不良品かどうか**

不良率 0.04 の工程から製品を 1 個取り出し、不良品なら 1、良品なら 0 とします。$X$ はベルヌーイ分布にしたがい

$$
E[X]=0.04,\qquad V[X]=0.04\times 0.96=0.0384
$$

です。

**例 2：0 と 1 のデータの平均は比率**

10 人にある案への賛否をたずね、賛成を 1、反対を 0 とすると、データが 1, 0, 0, 1, 0, 0, 1, 0, 0, 0 だったとします。平均は $3/10=0.3$ で、賛成の割合そのものです。
母比率 $p$ の推定量としての標本比率は、ベルヌーイ分布にしたがう変数の標本平均なので、期待値 $p$、分散 $p(1-p)/n$ をもちます。

**例 3：分散が最大になるのは $p=0.5$**

$p=0.5$ なら $V[X]=0.25$、$p=0.1$ なら $0.09$ です。母比率の見当がつかないときに、必要な標本の大きさを $p=0.5$（分散が最大）で計算するのはこのためです。

## 現場での使われ方

- **世論調査**：一人ひとりの回答を「賛成 1・反対 0」として、賛成率を 0 と 1 のデータの平均として推定します。
- **品質管理**：製品 1 個ごとの良・不良をベルヌーイ試行とみなし、不良品の数（二項分布）や不良率を管理します。
- **ウェブの改善**：1 回の表示で広告がクリックされたかどうかをベルヌーイ試行とみなし、クリック率を比べます。

## グラフ・イメージ

棒は 0 と 1 の 2 本だけです。$p$ を動かすと、1 の棒が $p$、0 の棒が $1-p$ の高さになります。$p=0.5$ で 2 本が同じ高さになり、このとき散らばりが最も大きくなります。

## 試験のポイント

- 期待値 $p$・分散 $p(1-p)$ をすぐに書けるようにします。二項分布の期待値 $np$・分散 $np(1-p)$ は、これを $n$ 回分足したものです。
- 「分散 $p(1-p)$ が最大になる $p$ は 0.5」は、標本の大きさの計算や母比率の区間推定で使います。
- 0 と 1 のデータの平均が比率になることから、標本比率に中心極限定理を使えることを押さえます。

## よくある間違い

- × ベルヌーイ分布の分散は $p$ → ○ 分散は $p(1-p)$ です。$p$ は期待値です。
- × 分散 $p(1-p)$ は $p$ が大きいほど大きい → ○ $p=0.5$ で最大で、$p=0.9$ と $p=0.1$ の分散は同じ 0.09 です。
- × 2 通りの結果は同じ確率で起こる → ○ 結果が 2 通りでも、確率が 0.5 ずつとは限りません。

# 第26章 その他の多変量解析手法

## 用語
| id | 用語 | 別名 | 重要度 | 選んだ理由 |
|---|---|---|---|---|
| multidimensional-scaling | 多次元尺度構成法 | MDS | A | 距離行列から配置を復元する代表手法 |
| classical-mds | 古典的MDS | 計量MDS、主座標分析 | B | 距離行列の固有値分解による導出 |
| nonmetric-mds | 非計量MDS | 順序尺度MDS | C | 順序情報のみを使う拡張 |
| canonical-correlation-analysis | 正準相関分析 | CCA | A | 2変数群の相関を最大化、固有値問題で導出 |
| canonical-variate | 正準変量と正準相関係数 | 正準変数 | A | CCAの結果の解釈・計算 |
| correspondence-analysis | コレスポンデンス分析 | 対応分析 | A | 分割表の行・列を低次元に配置 |
| quantification-theory | 数量化理論 | 数量化I〜IV類 | A | 質的変数を扱う日本発の手法群 |
| quantification-type-1 | 数量化I類 | - | B | 質的説明変数の回帰（ダミー変数回帰と同等） |
| quantification-type-3 | 数量化III類 | 双対尺度法 | B | コレスポンデンス分析と同等 |
| multiple-correspondence-analysis | 多重コレスポンデンス分析 | MCA | C | 多変量カテゴリデータへの拡張 |
| structural-equation-modeling | 構造方程式モデリング | SEM、共分散構造分析 | A | 潜在変数と因果構造のモデル化 |
| path-analysis | パス解析 | パス図 | B | SEMの基礎、直接効果・間接効果 |
| independent-component-analysis | 独立成分分析 | ICA | B | 非正規性を利用した信号分離 |
| goodness-of-fit-indices | 適合度指標 | GFI、RMSEA、CFI | C | SEMの評価 |

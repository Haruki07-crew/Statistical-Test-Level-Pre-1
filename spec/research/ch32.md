# 第32章 シミュレーション

## 用語
| id | 用語 | 別名 | 重要度 | 選んだ理由 |
|---|---|---|---|---|
| uniform-random-number | 一様乱数 | 疑似乱数 | A | 乱数生成の出発点 |
| linear-congruential-generator | 線形合同法 | LCG | B | 代表的な疑似乱数生成法、手計算可能 |
| inverse-transform-sampling | 逆関数法 | 逆変換法 | A | 指数分布などで導出が頻出 |
| rejection-sampling | 棄却法 | 採択・棄却法 | A | 採択確率と効率の計算 |
| box-muller-method | ボックス・ミュラー法 | - | A | 一様乱数から正規乱数を作る |
| monte-carlo-integration | モンテカルロ積分 | モンテカルロ法 | A | 推定量の分散・誤差の評価 |
| importance-sampling | 重点サンプリング | 重要度サンプリング | A | 重み付き推定、分散削減 |
| variance-reduction | 分散減少法 | 対照変量法、制御変量法 | C | モンテカルロの効率向上 |
| mcmc | マルコフ連鎖モンテカルロ法 | MCMC | A | ベイズ計算の標準手法 |
| metropolis-hastings | メトロポリス・ヘイスティングス法 | MH法 | A | 採択確率と詳細つり合いの導出 |
| gibbs-sampling | ギブスサンプリング | - | A | 条件付き分布からの逐次生成 |
| burn-in-convergence | バーンインと収束診断 | 自己相関、有効標本数 | B | MCMCの実践上の注意 |
| bootstrap | ブートストラップ法 | 再標本化 | A | 標準誤差・信頼区間の推定 |
| bootstrap-confidence-interval | ブートストラップ信頼区間 | パーセンタイル法 | B | 区間推定への応用 |
| jackknife | ジャックナイフ法 | - | A | バイアス・分散の推定 |
| permutation-simulation | モンテカルロ検定 | 乱数による検定 | C | 検定への応用（並べ替え検定は第13章） |

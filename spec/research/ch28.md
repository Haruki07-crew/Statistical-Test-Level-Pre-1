# 第28章 分割表

## 用語
| id | 用語 | 別名 | 重要度 | 選んだ理由 |
|---|---|---|---|---|
| contingency-table | 分割表 | クロス集計表 | A | 章の基本対象、周辺度数・同時度数 |
| two-by-two-table | 2×2分割表 | 四分表 | A | 各種指標の計算の土台 |
| relative-risk | 相対リスク | リスク比 | A | 疫学での標準指標、計算が頻出 |
| risk-difference | リスク差 | 寄与危険 | B | 相対リスクと対で使う |
| odds-ratio-interval | オッズ比の推定と区間推定 | 対数オッズ比のワルド区間 | A | 対数オッズ比の漸近分散で信頼区間（オッズ比自体は第18章） |
| sampling-schemes | 分割表の標本抽出モデル | ポアソン・多項・積多項 | A | 条件付けで分布が変わる点が頻出 |
| yates-correction | イェーツの連続修正 | イェーツの補正 | B | 2×2表のカイ二乗近似の補正 |
| mcnemar-test | マクネマー検定 | 対応のある2値データ | A | 対応のある比率の比較で頻出 |
| loglinear-model | 対数線形モデル | - | A | 多元表の独立性・交互作用を表す |
| hierarchical-loglinear-model | 階層モデル | 飽和モデル | B | モデルの階層性と自由度 |
| simpsons-paradox | シンプソンのパラドックス | 集計の逆転 | A | 層別と周辺の結論が逆転する典型 |
| mantel-haenszel-test | マンテル・ヘンツェル検定 | CMH検定 | A | 層別2×2表の併合検定 |
| mantel-haenszel-estimator | マンテル・ヘンツェル共通オッズ比推定量 | - | B | 層別を併合する推定量 |
| ordinal-contingency-table | 順序カテゴリの分割表 | 傾向性検定、コクラン・アーミテージ検定 | C | 順序性を用いた検定 |
| three-way-table | 3元分割表 | 周辺独立・条件付き独立・同時独立 | B | 独立性の階層構造 |
| residual-analysis-contingency | 分割表の残差分析 | 調整済み標準化残差 | C | セルごとの偏りの確認 |

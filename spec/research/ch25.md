# 第25章 因子分析・グラフィカルモデル

## 用語
| id | 用語 | 別名 | 重要度 | 選んだ理由 |
|---|---|---|---|---|
| factor-analysis-model | 因子分析モデル | 因子モデル | A | 観測変数を共通因子と独自因子で表す基本モデル、導出が問われる |
| common-factor-unique-factor | 共通因子と独自因子 | 独自性 | A | 分散の分解（共通性＋独自分散）の前提 |
| factor-loading | 因子負荷量 | 因子負荷行列 | A | 共分散構造の計算・解釈で頻出 |
| communality | 共通性 | コミュナリティ | A | 分散の分解の計算問題で頻出 |
| factor-rotation | 因子回転 | 直交回転・斜交回転 | A | 回転の不定性と解釈の単純化 |
| varimax-rotation | バリマックス回転 | - | B | 代表的な直交回転 |
| promax-rotation | プロマックス回転 | - | B | 代表的な斜交回転 |
| number-of-factors | 因子数の決め方 | カイザー基準、スクリープロット | B | 固有値1以上や適合度での選択 |
| factor-score | 因子得点 | - | B | 回帰法・バートレット法の推定 |
| maximum-likelihood-factor-analysis | 因子分析の最尤法 | 主因子法 | B | 推定法と適合度検定 |
| graphical-model | グラフィカルモデル | 確率的グラフィカルモデル | A | 変数間の依存構造をグラフで表す |
| undirected-graphical-model | 無向グラフィカルモデル | 共分散選択モデル、ガウス型グラフィカルモデル | A | 出題範囲に明記、精度行列の零成分と対応 |
| precision-matrix | 精度行列 | 逆共分散行列、濃度行列 | A | 条件付き独立と零成分の対応で頻出 |
| covariance-selection | 共分散選択 | Dempster | B | 精度行列の零成分を選ぶ手法 |
| directed-acyclic-graph | 有向非巡回グラフ | DAG、ベイジアンネットワーク | B | 因子分解表現と有向グラフィカルモデル |
| graphical-lasso | グラフィカルLasso | - | C | 疎な精度行列の推定 |

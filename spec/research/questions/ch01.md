# 第1章 事象と確率：問題づくりの調査メモ

問題・数値・解説はすべてオリジナル。以下は「よく解説される論点・つまずき」を拾うためだけに参照した。

| URL | 拾った論点（1行） |
|---|---|
| https://www.isc.meiji.ac.jp/~kikn/FIT/FIT4-prob.pdf | 条件付き確率は「条件の事象を新しい全体とみなす」比の考え方で説明されることが多い |
| https://www.info.kochi-tech.ac.jp/mfukumot/Lecture/IT/materials/lec03.pdf | 独立の定義 $P(A\cap B)=P(A)P(B)$ と排反の混同がつまずきやすい |
| https://www.physics.okayama-u.ac.jp/~otsuki/lecture/ynu2021/ynu_02.pdf | 検査の陽性的中率（事前確率が小さいと事後確率が低い）がベイズの定理の定番例 |
| https://metricgate.com/blogs/ja/base-rate-fallacy/ | 基準率の誤謬：事前確率を無視して感度を事後確率と取り違える |
| https://www.issoh.co.jp/md/tech/15236 | 事後確率 ∝ 尤度 × 事前確率 と捉えると計算の見通しがよい |

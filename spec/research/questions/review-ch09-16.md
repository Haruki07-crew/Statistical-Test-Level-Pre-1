## 直した問題

- q09-ci-mean-unknown-variance-2 / 「小数第3位まで」なのに tolerance が 0.002 で、丸めの幅と合っていなかった / tolerance を 0.001 にした（正確な値 1.9632 でも、与えた t 値を使った 1.9628 でも 1.963 になる）。
- q09-clopper-pearson-interval-1 / 解説の $B_{0.975}(1,20)$ は下側の分位点だが、この章のカイ二乗の添字は上側確率なので、読み違えるおそれがあった / 「Be(1,20) の下側97.5%点」と書き、記号の意味の違いを注記した（本文 clopper-pearson-interval.md の定義と同じ）。
- q10-multiple-testing-2 / ヒントの $\alpha'=1-0.95^{1/5}$ が答えの式そのものだった / 「$(1-\alpha')^5=0.95$ と整理して5乗根をとる」と、方針だけを示すヒントにした。
- q11-f-test-equal-variances-1 / 答えに $P(F(8,12)>3.0)$ が要るのに、その値が問題文になく、F 分布表では求められなかった / 「必要なら $P(F(8,12)\ge3.0)=0.0424$ を使ってよい」を問題文に加えた。
- q13-concordant-discordant-pairs-1 / 誤答 $3/5$ が何の間違いなのか解説に書かれていなかった / 「タイの4組を一致対に数えた $(8-2)/10$」と解説に加えた。
- q14-absorption-probability-2 / 「前問と同じ連鎖で」だけで連鎖が書かれておらず、ランダムに出題したときに解けなかった / 推移の内容を問題文に書いた。
- q15-gambler-ruin-problem-1 / ヒントの $D_i=i(N-i)$ に代入すると答えがそのまま出た / 1回目で場合分けする漸化式と境界条件を示し、「解は $i$ の2次式」とだけ書くヒントにした。
- q16-adjusted-r-squared-1 / 解説に「分母を $n-p$ にすると 0.5 になる」とあったが、実際は $1-0.40\times24/21=0.543$ / 解説の値を 0.543 に直した。

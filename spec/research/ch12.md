# 第12章 一般の分布に関する検定法

## 用語
| id | 用語 | 別名 | 重要度 | 選んだ理由（短く） |
|---|---|---|---|---|
| proportion-test | 母比率の検定 | 正規近似による検定 | A | 計算問題で頻出 |
| binomial-test | 二項検定 | 正確検定 | A | 厳密なp値の計算 |
| poisson-parameter-test | ポアソン分布の母数の検定 | | A | 母数λの検定 |
| two-sample-proportion-test | 2標本の比率の差の検定 | | A | プールした比率の利用 |
| goodness-of-fit-test | 適合度検定 | カイ二乗適合度検定 | A | ピアソンの統計量で頻出 |
| pearson-chi-square-statistic | ピアソンのカイ二乗統計量 | | A | 期待度数との差の計算 |
| independence-test | 独立性の検定 | | A | 分割表の検定、自由度の計算 |
| homogeneity-test | 同質性の検定 | | B | 独立性の検定との違い |
| g-statistic | 尤度比検定統計量（G統計量） | 逸脱度、G検定 | A | 出題範囲に明記、カイ二乗との比較 |
| expected-frequency | 期待度数 | | B | 自由度・近似条件の理解 |
| degrees-of-freedom-gof | 適合度検定の自由度（推定母数の影響） | | A | 母数を推定した場合の減少 |
| chi-square-approximation-condition | カイ二乗近似の条件 | 期待度数5以上 | B | 近似の妥当性 |
| residual-analysis-contingency | 調整済み標準化残差 | | C | どのセルが寄与するかの分析 |

| poisson-two-sample-test | 2標本ポアソン比較 | 条件付き二項検定 | B | 条件付き分布の導出 |
| kolmogorov-smirnov-test | コルモゴロフ・スミルノフ検定 | KS検定 | B | 分布の適合度検定の一種 |

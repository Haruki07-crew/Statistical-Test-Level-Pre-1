# 第30章 モデル選択

## 用語
| id | 用語 | 別名 | 重要度 | 選んだ理由 |
|---|---|---|---|---|
| model-selection | モデル選択 | - | B | 章の目的、予測精度と簡潔さの両立 |
| aic | AIC | 赤池情報量規準 | A | 定義と計算が最頻出 |
| bic | BIC | ベイズ情報量規準、シュワルツ規準 | A | AICとの違い、一致性 |
| kullback-leibler-divergence | カルバック・ライブラー情報量 | KLダイバージェンス | A | AICの導出の基礎 |
| expected-log-likelihood | 平均対数尤度 | 期待対数尤度 | B | AICの導出（バイアス補正） |
| cross-validation | 交差検証法 | CV、k分割CV | A | 実践上の最重要手法 |
| leave-one-out-cv | 一個抜き交差検証 | LOOCV | B | 線形回帰での簡便式 |
| overfitting | 過学習 | 過剰適合 | A | モデル選択の動機 |
| bias-variance-tradeoff | バイアス・バリアンスのトレードオフ | 偏りと分散 | A | 予測誤差の分解 |
| mallows-cp | マローズのCp | Cp規準 | A | 線形回帰のモデル選択、AICと関連 |
| information-criteria-comparison | 情報量規準によるモデル比較 | AIC差、赤池ウェイト | B | 実際の比較手順 |
| generalization-error | 汎化誤差 | 予測誤差 | B | 訓練誤差との違い |
| training-test-split | 訓練データとテストデータ | ホールドアウト法 | C | 評価の基本 |
| aicc | 補正AIC | AICc | C | 小標本での補正 |
| tic-ebic | TICと一般化情報量規準 | GIC、WAIC | C | AICの拡張 |

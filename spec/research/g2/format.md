## 試験形式（公式の案内による）
| 項目 | 内容 |
|---|---|
| 方式 | CBT（会場のパソコンで受ける） |
| 時間 | 90 分 |
| 問題数 | 35 問程度 |
| 解答 | 4〜5 肢の選択（選択肢を選ぶ、または番号を入力） |
| 配点・合格 | 100 点満点、60 点以上で合格 |
| 電卓 | 四則演算・%・√ の付いた一般的な電卓だけ（関数電卓は不可） |
| 数値表 | 標準正規分布表などの統計数値表が会場で配られる |

## 準1級との違い（作り方に関係する点）
- 準1級（25 問程度・5 肢選択と数値入力）に対し、2級は **35 問程度・選択式だけ**。1 問あたりは短く、基本的な計算と読み取りが中心。
- 記述統計（グラフ、要約統計量、ジニ係数、指数、移動平均）とデータの集め方が範囲のおよそ 3 分の 1 を占める。準1級の辞典にはこれらの用語がないか、扱いが浅い。
- 統計ソフトウェアの出力（回帰の係数表、分散分析表）を読み取る問題がある。

# 第31章 ベイズ法

## 用語
| id | 用語 | 別名 | 重要度 | 選んだ理由 |
|---|---|---|---|---|
| prior-distribution | 事前分布 | 事前確率 | A | ベイズ推論の出発点（他用語から参照される） |
| posterior-distribution | 事後分布 | 事後確率 | A | ベイズ推論の中心（他用語から参照される） |
| conjugate-prior | 共役事前分布 | - | A | 事後分布が閉じた形で求まる |
| beta-binomial-model | ベータ・二項モデル | - | A | 最頻出の計算例 |
| gamma-poisson-model | ガンマ・ポアソンモデル | - | A | 共役性の計算が頻出 |
| normal-normal-model | 正規・正規モデル | - | A | 精度の加算と重み付き平均 |
| noninformative-prior | 無情報事前分布 | 一様事前分布、不適切事前分布 | B | 事前知識がない場合の選択 |
| jeffreys-prior | ジェフリーズの事前分布 | - | B | フィッシャー情報量から導く、変換不変 |
| posterior-mean-map | 事後平均とMAP推定 | 事後最頻値 | A | ベイズ点推定の代表 |
| credible-interval | 信用区間 | 最高事後密度区間（HPD） | A | 信頼区間との解釈の違い |
| predictive-distribution | 予測分布 | 事後予測分布 | A | 新しい観測の分布の導出 |
| bayes-factor | ベイズファクター | - | B | モデル比較・検定 |
| marginal-likelihood | 周辺尤度 | エビデンス | B | ベイズファクターの構成要素 |
| hierarchical-bayes-model | 階層ベイズモデル | - | B | ハイパーパラメータに事前分布 |
| empirical-bayes | 経験ベイズ法 | - | C | ハイパーパラメータをデータから推定 |
| bayes-decision-theory | ベイズ決定理論 | ベイズリスク、損失関数 | C | 事後平均などの最適性の根拠 |

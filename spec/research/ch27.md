# 第27章 時系列解析

## 用語
| id | 用語 | 別名 | 重要度 | 選んだ理由 |
|---|---|---|---|---|
| time-series | 時系列データ | - | B | 前提となる基本概念、トレンド・季節・不規則変動 |
| weak-stationarity | 弱定常性 | 共分散定常性 | A | 時系列解析の出発点で頻出 |
| strict-stationarity | 強定常性 | 厳密定常性 | C | 弱定常性との違い |
| autocovariance-autocorrelation | 自己共分散・自己相関 | ACF | A | 計算問題で頻出 |
| correlogram | コレログラム | 標本自己相関図 | B | モデル同定に使う図 |
| partial-autocorrelation | 偏自己相関 | PACF | A | AR次数の同定 |
| white-noise | ホワイトノイズ | 白色雑音 | A | すべてのモデルの構成要素 |
| ar-model | ARモデル | 自己回帰モデル | A | 定常条件・自己相関の計算が頻出 |
| ma-model | MAモデル | 移動平均モデル | A | 自己共分散の導出が頻出 |
| arma-model | ARMAモデル | - | A | AR・MAの統合、定常性・反転可能性 |
| arima-model | ARIMAモデル | 和分過程 | A | 階差による非定常の扱い |
| yule-walker-equations | ユール・ウォーカー方程式 | - | A | ARの係数推定・自己相関の導出 |
| stationarity-condition | 定常条件 | 特性方程式、後退作用素 | A | 特性根が単位円の外側で判定 |
| invertibility | 反転可能性 | 可逆性 | B | MAモデルの条件 |
| unit-root | 単位根 | 単位根検定、ディッキー・フラー検定 | A | 非定常性の検定 |
| spectrum | スペクトル | パワースペクトル、ピリオドグラム | B | 周波数領域での表現 |
| seasonal-adjustment | 季節調整 | 季節階差、SARIMA | B | 季節変動の除去・モデル |
| forecasting | 予測 | 最適予測、予測誤差 | B | ARモデルの1期先予測など |
| random-walk-time-series | ランダムウォーク過程（時系列） | - | C | 単位根の典型例（確率過程としては第15章） |

# 模擬試験の作り方（content/exam_sets/setNN.yaml）

本番と同じ形式（spec/research/exam-format.md）：**1セット 25 問・90 分・5肢選択と数値入力・各4点・60点以上で合格**。
質の基準は spec/research/exam-style.md、セットごとの章の配分は spec/research/exam-blueprint.md。

## 著作権
過去問・『統計学実践ワークブック』・Web 記事の問題文・数値・解説は使わない。論点だけを参考に、状況・数値・文章はすべて自分で作る。

## ファイル
| ファイル | 内容 |
|---|---|
| `content/exam_sets/setNN.yaml` | 問題（数値は «名前» で書き、generator の値を差し込む） |
| `generator/setNN.py` | `values()` が `{大問id: {名前: 値}}` を返す。正解・選択肢の数値はここで計算する（手計算で書かない） |
| `verify/exam_setNN.py` | 検算：正解を作問とは別の方法（scipy の分布関数・シミュレーション・sympy・定義からの直接計算）で求め直す |
| `verify/exam_review/setNN.md` | 見直し（math-checker）の指摘と直した内容 |

## 形式
```yaml
set: 1
title: 模擬試験 第1回
minutes: 90
problems:                         # 大問。1つの状況から1〜3問の小問を出す
  - id: s01p01                    # s + セット2桁 + p + 大問2桁
    title: 製造ラインの欠陥数       # 画面に出す見出し（題材がわかる短い名前）
    context: |                    # 状況設定（Markdown・数式可）。小問すべてに共通
      ある製造ラインでは、1 日に見つかる欠陥の数 $X$ が平均 $\lambda$ のポアソン分布に従うとする。
      10 日間の欠陥数の合計は «T» 個だった。
    items:
      - id: s01p01a               # 大問id + a, b, c
        chapter: 8                # 主に使う章（出題配分の集計に使う）
        terms: [maximum-likelihood-estimation, fisher-information]   # 関係する用語ページ（plan.yaml の id）
        topic: ポアソン母数の最尤推定量の標準誤差   # 論点を1行で。30セット全体で重複してはいけない
        level: 標準                # 基本 / 標準 / 応用（1セットで 7 / 13 / 5）
        definition: false         # 用語の定義を聞くだけの問題なら true（1セット2問まで）
        type: numeric             # choice（5肢選択） / numeric（数値入力）
        question: |
          $\lambda$ の最尤推定量の標準誤差の推定値を求めよ。
        answer: «se»              # numeric：数値（generator の値）。choice：正解の選択肢の番号 0〜4
        tolerance: 0.01           # numeric のみ。許容範囲（絶対誤差）
        answer_format: 小数第2位まで（四捨五入）で答えよ。±0.01 の差まで正解とする。
        explanation: |
          **方針** …
          **途中式** …（省略しない）
          **答え** …
          **間違えやすい点** …（誤答の元になる間違い）
          **別解** …（あれば）
      - id: s01p01b
        type: choice
        choices:                  # 5つ。数値は «名前»
          - «c0»
          - …
        answer: 2
        distractors:              # 選択肢と同じ順。正解は「正解」、誤答はどの間違いから来たか（内部メモ。画面には出さない）
          - 分散と標準偏差を取り違えた
          - …
          - 正解
          - …
```
- 解説の見出しは `**方針**` `**途中式**` `**答え**` `**間違えやすい点**` をこの順に必ず書く（`**別解**` は任意）。関係する用語ページへのリンクは terms から画面が自動で付ける。
- 画面では選択肢を**シャッフルしない**（本番どおり）。解説では「選択肢 3」のように番号で指してよいが、値で指すほうがよい。
- 数値入力は丸め方と許容範囲を必ず書く。許容範囲は丸めの幅に合わせる（小数第2位まで → ±0.01、整数 → ±0.5 未満）。
- 正規分布表・t 表・χ² 表・F 表、指数・対数・平方根以外の関数値など、一般電卓で出せない値は**問題文（context か question）に示す**。示した値だけで正解が出るようにする（generator も示した値を使って計算する）。
- 流儀が分かれるもの（幾何分布の台、ガンマ分布の尺度とレート、標本分散の割る数、AIC の定義、片側・両側）は問題文に明記する。
- 「適切なものを選べ」型の文章の選択肢は、正しいものがただ1つになるよう、誤りの文は明確に誤り（反例が示せる）にする。

## 良い問題の条件（全問）
1. 本番らしい：1 つの状況から複数の論点を問う／導出と計算を組み合わせる／実務に近い題材（品質管理・医療・マーケティング・金融・Web・気象・交通・農業・教育など）。定義だけの問題は1割以下。
2. 正解がただ1つで、問題文だけで解ける。
3. 誤答は受験者がしやすい間違いから作る（自由度、分散と標準偏差、片側と両側、不偏分散と標本分散、連続修正、尺度とレート、条件付きと同時、有限母集団修正、AIC のパラメータ数 など）。
4. 本番の制限時間内（1問約3.6分）で電卓で解ける計算量。
5. 30 セット全体で同じ問題・数値だけ違う同じ型の問題を繰り返さない（topic を重複させない。既存セットの topic 一覧は `scripts/check_exam.py --status` の前に `grep -h "topic:" content/exam_sets/*.yaml` で見る）。

## 作り方と品質チェック（3段階を通らない問題は公開されない）
1. **自動検査**：`.venv/bin/python scripts/check_exam.py --set N`（必須項目・選択肢5つで重複なし・正解1つ・丸め方と許容範囲・«»の未定義・用語id・章の配分・難易度の割合・topic の重複）と `.venv/bin/python scripts/check_math.py`（数式）。
2. **検算**：`.venv/bin/python verify/exam_setNN.py`。部品は verify/examcheck.py（`E.num` `E.choice` `E.check` `E.done`）。正解を generator とは別の方法で求め直し、全小問が OK になること。結果は内容のハッシュつきで verify/exam_results/setNN.json に保存され、あとで問題を書き換えると自動で非公開になる。
3. **見直し**：作問に関わっていない math-checker サブエージェントに、問題文の曖昧さ・正解がただ1つか・誤答が本当に誤りか・解説の飛躍を確認させ、指摘をすべて直して verify/exam_review/setNN.md に記録する。直し終えたら `.venv/bin/python scripts/exam_review.py --set N` で見直し済みを記録する（内容のハッシュつき）。直したら検算もやり直す。

build.py は、3段階すべてに通った（ハッシュが一致する）小問だけでできたセットを公開する。1問でも欠けたセットは公開しない。

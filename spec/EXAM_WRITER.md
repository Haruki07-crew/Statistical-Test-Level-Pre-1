# 模擬試験の作問担当への指示（1人1セット）

あなたは統計検定準1級のオリジナル模擬試験を1セット作る。利用者は寝ているので質問しない。迷ったら最も妥当な案で進める。質を最優先し、50分程度で仕上げる。ほかの担当が別のセットを並行して作っている。

## 最初に読むもの
- CLAUDE.md（著作権：過去問・『統計学実践ワークブック』・Web 記事の問題文・数値・解説は使わない）
- spec/EXAM.md（形式と規則。この通りに書く）、spec/research/exam-style.md、spec/research/exam-format.md
- 質の見本：content/exam_sets/set01.yaml・generator/set01.py・verify/exam_set01.py
- 見直しで見つかった誤りの例：verify/exam_review/set0*.md（解説の丸めの言い回し、表示した途中の値と次の式の食い違い、相関行列でないものを相関行列と呼ぶ、数表の流儀の書き忘れ、離散分布での「最強力」の言い過ぎ、ユークリッド距離になりえない距離表、パラメータ数の数え違い）。同じ誤りをしない。

## 作るもの（あなたのセット番号を NN とする）
content/exam_sets/setNN.yaml、generator/setNN.py、verify/exam_setNN.py の3つだけ。ほかのファイルは編集しない。git commit はしない。

## 要件
- 25問、`minutes: 90`。各小問の `chapter` は指定された章の集合（各1回）と完全に一致させる。
- 難易度は 基本7・標準13・応用5。形式は5肢選択 17〜19、数値入力 6〜8。`definition: true` は2問まで。
- 大問は 11〜14 個。現実的な状況設定で、いくつかの大問は前の小問の結果を使う2〜3問の小問にする。
- **同じ型の問題を繰り返さない**：書く前に `grep -h "topic:" content/exam_sets/*.yaml` で既存の論点を確かめ、数値や題材を変えただけの同じ型を避ける。同じ章でも別の小論点を選ぶ。最後にもう一度確かめる。
- 計算で出る数値はすべて generator の «名前» で差し込む。数表・関数電卓が要る値は問題文に示し、generator はその丸めた値から計算する（一般電卓で解くと必ず正解の値になる）。表示した途中の値は次の式と整合させる。
- 誤答が丸めると正解と同じにならないこと。文章の選択肢は正しいものがただ1つ。流儀（母数の取り方・片側両側・不偏か最尤か・自由度・AIC/BIC の定義・連続修正・数表の流儀）を明記する。
- distractors に各誤答の元になる間違いを書く。
- 解説は **方針** → **途中式**（省略しない）→ **答え** → **間違えやすい点**（→ 任意で **別解**）。日本語で、わかりやすく厳密に。
- verify/exam_setNN.py は verify/examcheck.py を使う（E = Exam(NN); E.num / E.choice / E.check; E.done()）。全小問を generator と別の方法（scipy の分布関数、シードを固定したシミュレーション、sympy、全列挙）で求め直し、問題文に示した数表の値もすべて確かめる。

## 終わりの条件（すべて満たすまで直す）
- `.venv/bin/python scripts/check_exam.py --set NN` で自分のセットのエラー 0（topic の重複を含む）
- `.venv/bin/python scripts/check_math.py` で問題 0
- `.venv/bin/python verify/exam_setNN.py` で全問 OK

## 最後の報告（短く）
大問の見出しと章、自信のない小問とその理由、3つのコマンドの最後の行。

## 同じ型の扱い（全セット共通の約束）
- 各章は30セットすべてに出るので、章の中の小論点を広く使う（例：第9章なら t 区間・対応のある区間・ウェルチ・分散のカイ二乗区間・分散比の F 区間・比率のワルド・ウィルソン・正確な区間・比率の差・ポアソン率・指数平均・幅から標本の大きさ・変換と逆変換・予測区間 など）。
- 番号の小さいセットが優先。同じ型（求める量と解き方が同じ）がすでにあれば別の小論点にする。
- どうしても章の小論点が尽きる場合に限り、同じ型は全体で2回まで。その場合は求める量・与える情報・題材をすべて変える（例：1回目は区間の上限、2回目は必要な標本の大きさ）。
- 確認：`.venv/bin/python scripts/exam_topics.py --chapter 章番号`
